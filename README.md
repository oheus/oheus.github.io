# AI Token & Local LLM Cost Calculator (방치형 웹앱)

이 사이트는 서버비 0원, 사후관리(CS) 0%로 영구 방치하며 검색 유입을 통해 애드센스 광고 수익을 얻도록 설계된 정적 1페이지 웹 유틸리티입니다.

## 1. 3분 무료 배포 방법 (선택 1: Vercel)
1. [Vercel](https://vercel.com)에 무료 가입 (GitHub 계정 연동)
2. `micro-utility-web` 폴더를 GitHub에 업로드 후 Vercel에서 `Import Project` 클릭
3. `Deploy` 버튼을 누르면 1분 만에 `https://당신프로젝트.vercel.app` 무료 주소 발급 완료! (무료 HTTPS 자동 적용)

## 2. 무료 배포 방법 (선택 2: GitHub Pages)
1. GitHub 저장소 생성 후 `index.html`, `style.css`, `app.js` 푸시
2. Settings -> Pages -> Branch를 `main`으로 선택하고 Save 클릭
3. 2분 후 무료 웹사이트 오픈!

## 3. 구글 애드센스 광고 코드 넣는 위치
사이트가 개설된 후 애드센스 승인을 받으면, `index.html` 내 아래 주석 부분에 구글에서 받은 `<script>` 광고 태그를 복사-붙여넣기만 하면 끝납니다:
- `<!-- 구글 애드센스 상단 반응형 슬롯 -->` 내부
- `<!-- 구글 애드센스 하단 반응형 슬롯 -->` 내부
